# Sea Explorer 3D

An immersive underwater 3D exploration experience built with Three.js. Explore various sea creatures in their natural habitat with high-definition textures, realistic lighting, and an interactive "Inspect Mode."

## Features

- **Realistic Sea Creatures**: Includes detailed 3D models of Humpback Whales, Great White Sharks, Sea Green Turtles, Jellyfish, Gourami, and Starfish.
- **High-Definition Textures**: Custom HD textures including BaseColor, Normal, Roughness, and Metallic maps for a professional look.
- **Advanced Lighting**: Realistic underwater atmosphere with cinematic studio lighting in Inspect Mode.
- **Interactive Inspect Mode**: Click on any animal to view it in a high-detail study environment with descriptive facts.
- **Atmospheric Effects**: Marine snow (floating particles), exponential fog, and dynamic animations for a "real sea" feel.

## Visual Enhancements

- **Realistic Mouths**: Internal mouth parts are textured with vibrant blood red and wet organic finishes.
- **Glassy Eyes**: Realistic deep dark black glassy eyes with sharp highlights.
- **Ocean Floor**: Detailed sandy sea floor base in Inspect Mode for better grounding.

## Setup

1. Clone the repository.
2. Open `index.html` in a web browser (using a local server like Live Server is recommended for GLTF model loading).
3. Explore the ocean!

## Technologies Used

- [Three.js](https://threejs.org/) - 3D Engine
- JavaScript (ES6+)
- CSS3 & HTML5
